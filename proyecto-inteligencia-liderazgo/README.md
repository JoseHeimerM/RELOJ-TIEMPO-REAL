# Proyecto: Inteligencia Existencial y Liderazgo Servicial

Este proyecto es una página web hecha con **React + Vite** para exponer dos temas:

- Inteligencia Existencial
- Liderazgo Servicial

Incluye:
- Explicación de ambos temas
- Ideas grandes de juegos participativos
- Propuesta de dramatización aplicada a la policía
- Diseño moderno y responsive

## Cómo usarlo

1. Instala dependencias:

```bash
npm install
```

2. Ejecuta el proyecto:

```bash
npm run dev
```

3. Abre el enlace local que te muestre Vite en el navegador.

## Estructura

- `src/App.jsx`: contenido principal de la página
- `src/main.jsx`: punto de entrada
- `src/styles.css`: estilos
- `index.html`: archivo base
- `vite.config.js`: configuración de Vite

## Subir a GitHub

1. Crea un repositorio nuevo en GitHub.
2. Sube todos estos archivos.
3. Haz commit inicial.
4. Opcional: despliega en Vercel o Netlify.
